# Oneiro Formats — v0.1

All files use the same Oneiro syntax; the extension tells tooling what to expect.

| Ext | Meaning |
|---|---|
| `.onr` | Script / episode |
| `.onchar` | Character |
| `.onset` | Set (environment) |
| `.onlock` | Resolved layout (generated; edit values and add `pinned: true` to keep them) |
| `.onstyle`, `.onclip` | Planned (custom styles, reusable animation clips) |

## 1. Project layout

```
my_series/
  oneiro.toml              # name, default_style, fps, width, height
  script.onr               # or episodes/ep01/script.onr
  script.onlock            # generated
  state.out                # generated: story state at the end of the episode
  library/
    characters/*.onchar
    sets/*.onset
    sounds/*.wav   music/*.wav
  audio/                   # voices and takes
  docs/ai/                 # bible.md, style guide, vocabulary.md (generated by `oneiro vocab`)
  out/                     # renders
```

A built-in global library (rig, head/eye/mouth/body parts, wardrobe, props) ships with the engine.

## 2. Character

```
character Marta {
  rig: library.rigs.biped_cutout
  build {
    head:  library.heads.round    { size: 1.0, skin_tone: #F2C9A0 }   # round | square | oval; hair: #RRGGBB, bald: 1
    eyes:  library.eyes.ovals     { spacing: 0.4 }                     # dots | ovals | wide
    mouth: library.mouths.visemes_basic
    body:  library.bodies.kid     { height: 1.0 }                      # kid | adult | round
  }
  wardrobe { default: [red_beanie, blue_coat, jeans, black_shoes] }
  voice { provider: file, pitch: 235 }   # or: provider: elevenlabs, voice: "<id>", speed: 1.1  (see 07-audio.md)
  sheet { age: 9, traits: [stubborn, impatient], notes: "Never takes the beanie off." }
  styles { cutout_2d: auto }
}
```

A character is **Rig + Skin (per style) + Face + Wardrobe + Voice + Sheet**. Parts and wardrobe come from the
global library (see `oneiro vocab`); this is the "character as blocks" builder (tier A). The `sheet` is for humans
and AI. The face has mouth shapes (visemes) A/E/O/U/S/FV/rest, a blink, eyebrows and expressions.

## 3. Set

```
set diner {
  size: 8m x 6m
  height: 3m
  palette { wall: #EBDFC2, wall_alt: #E0D1AC, floor: #DCD6C2, floor_alt: #34344A, trim: #B22A36 }
  anchors {
    door:    { pos: (-3.4, -1.0), facing: east }
    counter: { pos: (0.0, 2.35), solid: true }
    stool_2: { pos: (0.9, 1.4), seat: true, facing: north }
    clock:   (2.5, 2.15, 2.95)
  }
  props {
    counter:  library.props.counter    { at: (0.0, 2.35), width: 5.2 }
    stool_2:  library.props.stool      { at: (0.9, 1.4) }
    clock:    library.props.wall_clock { wall: north, at: 2.5, height_at: 2.15 }
    window_1: library.props.window     { wall: north, at: -2.3 }
    door:     library.props.door       { wall: west, at: -1.0 }
  }
}
```

Props: `counter stool table wall_clock window door pie_case`. Wall props take `wall` (north/south/east/west),
`at` (position along the wall) and optionally `height_at`. A set is a real 3D room rendered in perspective, so
cameras can go anywhere; characters are camera-facing cutouts that turn (front, profile, back) as the camera moves.

## 4. Lock file

```
lock "script.onr" {
  scene 1 {
    place Marta { pos: (0.900, 1.400), yaw: -43.5deg, pinned: false }
    shot 2 { source: "camera medium on Marta", pos: (-1.2, 1.1, 1.1), target: (0.9, 1.1, 1.4), fov: 29.9deg, roll: 0.0deg, pinned: false }
  }
}
```

- Written by `oneiro render`. Unpinned values are recomputed every time.
- Set `pinned: true` (after editing a value, e.g. by dragging a camera in the IDE) and the solver will never
  overwrite it. If a pinned shot's `source` no longer matches the script, `W3001` warns you.

## 4b. Project manifest

`oneiro.toml`: `name`, `default_style`, `fps`, `width`, `height`.

## 5. AI context (`docs/ai/`)

`bible.md` (world, tone, continuity), a style guide, and `vocabulary.md` generated by `oneiro vocab`, so the AI never
invents syntax. Include these in the AI's context before asking it to write or edit scenes.
